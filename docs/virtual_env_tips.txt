Python virtual environments
===========================

Install the Python venv support package with your operating system's package
manager when it is missing. On Debian or Ubuntu:

    sudo apt-get install python3-venv

Create and activate a project-local environment:

    python3 -m venv .venv
    source .venv/bin/activate

Install Python tools inside the active environment, without sudo:

    python -m pip install --upgrade pip
    python -m pip install flake8 autopep8

Deactivate the environment when finished:

    deactivate

Use `--system-site-packages` with `python3 -m venv` only when the project
needs packages already installed for the system Python. Avoid installing
project tools with `sudo pip`; that can conflict with packages managed by the
operating system.
